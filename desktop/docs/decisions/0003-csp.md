# 0003 - Content Security Policy

*Previously an open question; decided alongside the MPL-2.0 licensing pass.*

## Decision
Release builds run under a strict CSP set in `tauri.conf.json`: same-origin
scripts only, media and images additionally allowed from the asset protocol
plus `blob:`/`data:` (poster frames, waveform tiles, the grain overlay),
inline styles permitted (component `style={{...}}` attributes are everywhere),
and IPC endpoints named explicitly. Dev builds use a permissive `devCsp` so
Vite's injected HMR scripts and websocket keep working.

## What stays open
The asset protocol scope is still `["**"]` - a video editor opens arbitrary
user files, so a narrower scope would be a lie. The CSP now bounds what a
compromised page could *do* with that reach (no foreign script, no exfil
targets beyond IPC), which was the actual risk the old note deferred.

## What would change our mind
Rendering anything remote or user-authored beyond media files - templates, a
plugin UI, an update notice - forces this list open again, item by item.
