# Decision log

One file per decision that would otherwise be invisible in the code. Short.
Written for whoever opens this repo after a long gap - usually you.

Format: what we decided, why, what it costs, and what would change our mind.

Numbering is append-only. A note that stops earning its place is deleted, its
number is never reused, and git history keeps the text - which is why the log
can start past 0001.
